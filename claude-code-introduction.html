STEP 1 ・ 準備工具

1.1 安裝 Node.js

為什麼要裝？Node.js 是 Claude Code 的「引擎」。沒裝它，Claude Code 跑不起來，就像汽車沒引擎。
  1. 1
    打開瀏覽器，前往 https://nodejs.org 這是 Node.js 官方網站，安全可信
  2. 2
    點擊首頁綠色大按鈕「Get Node.js®」 會跳到下載頁面
  3. 3
    下載頁確認頂端顯示「LTS」（已預設好），點「Windows Installer (.msi)」下載 LTS = 長期支援版，公司用比較穩定；別點到 Current
  4. 4
    打開下載的 .msi 檔，全部按「Next」到底，最後按「Install」。完成後關掉視窗（不必重開機） 不必更改任何設定，預設就是對的

STEP 1 ・ 準備工具

1.2 安裝 Git for Windows

為什麼要裝？Git 是「檔案的時光機」，能記住每一次修改、隨時回到舊版本。之後上傳 GitHub 也要靠它。
  1. 1
    打開瀏覽器，前往 https://git-scm.com/download/win 會自動下載 Windows 版安裝檔
  2. 2
    打開下載的 .exe 檔
  3. 3
    全部按「Next」用預設值（畫面會問很多次，全部 Next 就好） 預設選項就是最佳選項，不必改
  4. 4
    最後按「Install」，完成後關閉

STEP 1 ・ 準備工具

1.3 確認兩個工具都裝好

按 Win + X，選「終端機」或「Windows PowerShell」，貼上下面兩行（一行一行貼）：

PS > node -v

✅ 看到類似 v20.11.0 的版本號 = 成功

PS > git --version

✅ 看到類似 git version 2.43.0 = 成功

如果出現「not recognized」：請完全關掉 PowerShell，重新打開再試一次。仍然不行就重開電腦。

STEP 2 ・ 安裝 Claude Code

2.1 一行指令裝好

確認 PowerShell 還是打開的狀態，貼上這一行，按 Enter：

PS > npm install -g @anthropic-ai/claude-code
會發生什麼：畫面會跑一堆英文字，這是正常的，等它跑完（約 1-2 分鐘）。看到 added XXX packages 就代表安裝成功。
指令在做什麼？
• npm = Node.js 內建的「軟體商店」
• install -g = 全電腦都能用的方式安裝
• @anthropic-ai/claude-code = Claude Code 的官方包

STEP 2 ・ 安裝 Claude Code

2.2 首次啟動與登入

  1. 1
    在 PowerShell 輸入 claude 並按 Enter 這會啟動 Claude Code
  2. 2
    第一次會問你登入方式，選「Claude account with subscription」（用 Claude 訂閱帳號）
  3. 3

  4. 4
    回到 PowerShell，看到「Welcome to Claude Code」就成功了 🎉
結束的方式：輸入 /exit 或按 Ctrl + C 兩次。

STEP 3 ・ 推到 GitHub

3.1 申請 GitHub 帳號

GitHub 是什麼？「雲端版的時光機檔案櫃」，你的程式碼、文件放在這裡，同仁可以一起看一起改。
  1. 1
    打開瀏覽器到 https://github.com，點右上「Sign up」
  2. 2
    填 Email、密碼、帳號名（建議用自己 Email；帳號名之後改不了，想清楚）
  3. 3
    收信驗證 Email
  4. 4
    註冊完成後，記下你的「使用者名稱」，下一步要用

STEP 3 ・ 推到 GitHub

3.2 把專案準備好（本機端）

假設資料夾在桌面叫 my-project，依序貼入三行指令：

PS > cd $HOME\Desktop\my-project
PS > git init
PS > git add . ; git commit -m "first commit"
三步在做什麼： cd 進入資料夾 → init 建時光機 → add + commit 把目前所有檔案加入 Git，然後建立第一個版本紀錄。
STEP 3
11
STEP 3 ・ 推到 GitHub

3.3 在 GitHub 建倉庫，推上去

  1. 1
    GitHub 網頁右上「+」→「New repository」
  2. 2
    填倉庫名稱（如 my-project），不要勾「Add a README」 勾了會跟你本機的 commit 衝突
  3. 3
    點「Create」後，複製畫面上 …or push an existing repository 那段的兩行指令貼到 PowerShell：
PS > git remote add origin https://github.com/你的帳號/my-project.git
PS > git branch -M main && git push -u origin main
第一次會跳出登入視窗：選「Sign in with your browser」，授權後就上傳完成。回到 GitHub 網頁重新整理，檔案就在了 🎉

常見問題 FAQ

Q1 找不到 claude 指令

關掉 PowerShell 重開。若仍不行，重開電腦，確保 Node.js PATH 已生效。

Q2 git push 一直要密碼

GitHub 已不接受密碼，要用瀏覽器授權或 Personal Access Token。建議第一次直接用瀏覽器登入。

Q3 npm install 卡住或紅字

檢查網路。若公司有 Proxy，請聯絡 IT。或者試試手機開熱點。

Q4 Claude 答錯怎麼辦

直接告訴它「不對，應該是…」，它會修正。多問細節、給多一點背景，答案會更準。

Q5 怎麼結束 claude

輸入 /exit 或連按兩次 Ctrl + C。

Q6 公司資料安全嗎

Claude Code 在你本機跑。內容會傳到 Anthropic API 處理（同 ChatGPT 邏輯），不會被當訓練資料。敏感內容請先去識別化。

進階 ・ 套用現成模板

從 skills.sh 安裝現成 Skill

Skill 是什麼？把「常用任務的做法」打包好的範本。例：「翻譯 PDF」「整理 Excel」「畫流程圖」。裝起來後，Claude 就學會這個技能。
  1. 1
    打開瀏覽器，前往 https://www.skills.sh/ 社群版的 Skill 商店，全部免費、開源
  2. 2
    瀏覽分類，找到想要的 skill（每個 skill 頁面都有使用說明 + 安裝指令）
  3. 3
    複製該頁面提供的安裝指令，到 PowerShell 貼上、按 Enter 通常是一行 npx 或 git clone 指令
  4. 4
    回到 Claude Code，輸入 /help 確認新 skill 已出現在清單裡
💡 推薦先試試：看到喜歡的就裝，不喜歡用 rm 刪掉資料夾就好，不會弄壞 Claude Code。
