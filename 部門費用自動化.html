01 — Challenge

人工月報的三大瓶頸

品保費用涉及五個廠區、數十個會計科目、橫跨 24+ 個月歷史對照， 傳統 Excel 人工彙整流程在規模化下逐漸暴露結構性問題。

📑
跨表彙整費時且易錯
費用、營收、人頭數分散在不同分頁；每次月報需手動樞紐分析、串接 VLOOKUP、 重算 MoM 與 YoY，單次出報耗時 4–8 小時， 公式拉錯一格全月數據連動失準。
🔍
異常憑經驗、無客觀依據
費用是否「異常」全靠資深同仁主觀判斷，缺乏統計門檻。 營收稀釋效應常讓費用率「看起來正常」， 但實際固定成本已悄悄擴張，傳統指標完全看不出來。
📄
靜態 PDF 無法鑽取
PDF/PPT 報告交出去就定型，主管想多看一個廠、換一個年份比較， 只能再請部門重做一份。資料一旦凍結，決策節奏被報告週期綁住。

03 — Methodology

三層分析方法論

不只是把 Excel 視覺化 —— 系統內建統計管制、多維拆解與規則式判讀引擎， 讓主管看到的不只是數字，而是「現在到底發生了什麼事」。

L1
統計管制
UCL / LCL 管制圖
費用占營收比以歷史 27 個月為基線，計算 UCL（μ+1σ）、LCL（μ−1σ）。 疊加 MA3 / MA6 移動平均、綠 / 黃 / 紅三段管制帶（2% / 3% 門檻基於歷史 P25 / P75 校準）。
💡 客觀判斷費用率是否真的「異常」，不再憑感覺
L2
三層拆解
可控 / 不可控 / 人均
剝離營收波動，從三個獨立維度檢視：可控費用率 MoM（變動成本）、 不可控同期比 YoY（固定成本擴張速度）、 人均費用 YoY（單位人力效率）。
💡 三維交叉判讀，避免被單一指標的營收稀釋誤導
L3
規則判讀
Verdict 自動結論
三維布林旗標組合，輸出 6 種預設情境的判讀文字（合理成長 / 實質失控 / 固定擴張 / 變動偏高 / 全部穩定 / 部分偏離）， 失控情境再追加 YoY +5 萬以上 top 3 主因科目。
💡 主管直接看結論，不用自己解讀數字
▸ Verdict 規則矩陣（節錄）
三維旗標組合 判讀文字 等級
不可控漲、可控穩、人均穩 不可控費用上升主要由擴編帶動（人均未漲），屬合理成長 🟢 ok
可控漲、人均漲 可控費用率與人均同步上升，實質失控需介入 🔴 warn
人均漲、可控穩 人均費用上升但可控費用率穩定，留意固定成本擴張 🟡 caution
三項皆穩 拆解後各項穩定，費用率波動主要來自營收 🟢 ok
其他 部分項目偏離，建議展開廠區主因確認 🟣 info
04 — Coverage

報告功能涵蓋

單一報告整合十類分析區塊，從總覽 KPI 到科目級異常追蹤， 支援即時切換年 / 月 / 廠 / 類型多維篩選。

01
六大 KPI 卡
集團營收、品保總費用、費用占營收比、YTD 累計、預算執行率、人事費占比。MoM 變動以紅 / 綠醒目標示。
02
AI 本月摘要
Claude API 接收結構化指標，生成中文 bullets：MoM / YoY 變化、管制帶警示、異常科目明細、廠區主因拆解。
03
費用 vs 營收趨勢
混合圖：費用柱狀 + 營收折線，肉眼判斷費用是否與營收同向變動。
04
費用占比管制圖
綠 / 黃 / 紅背景區帶 + UCL / LCL 紅虛線 + MA3 / MA6 + 趨勢線，四層指標疊加。
05
人事費 / 各廠人數趨勢
人事費占比與五廠人頭數同步呈現，捕捉「人縮快於費用」與「擴編未反映在費用」兩種訊號。
06
可控 / 不可控拆分
薪資 / 勞健保 / 折舊 / 攤提歸入不可控；加班費 / 旅費 / 檢測費 / 物料歸入可控。雙軸對比月度趨勢。
07
預算 vs 實際 + 執行率
五廠各自預算進度條（Burn Rate），超 / 達 / 未達門檻自動配色，年底前可視化「會不會超支」。
08
Run Rate 全年預測
以已知月份的實績外推剩餘月份，給出全年預估值，超預算月份紅字警示。
09
廠區科目明細
下鑽到月 × 廠 × 科目層級金額表，含 MoM、YoY、vs 前 3 月均值的差異欄。
10
異常 Top 5 + 單月偵測
超 / 低均值門檻自動標記，同步列出貢獻最大的廠區與科目原因 chips。
05 — Hidden Insights

系統挖出的關鍵發現

自動化的真正價值，不只是「把人做的事做快」， 而是「揭露人眼看不到的訊號」。以下是平台運轉至今三個最有代表性的發現。

Finding 1 · 拆解判讀的價值
2026/02 黃區邊緣 → 拆解後其實健康
該月份總費用率 2.99%，幾乎踩到紅區門檻，傳統判讀會直接亮警報。 但三維拆解後 可控費用率穩定、不可控未漲、人均也穩 —— 系統判讀為 🟢 「拆解後各項穩定，費用率波動主要來自營收」。
意義：證明「黃區月份」往往是營收稀釋造成的假警報，傳統觀察會誘導企業做出錯誤的成本縮減決策。
Finding 2 · 被薪資減少蓋過的訊號
2025 全年人均 YoY 多數 +10% 以上 → 傳統指標完全看不到
2025 年人事費下降（人從 91 縮到 69），總費用率與不可控 YoY 都呈現「正常或下降」。 但人均費用 YoY 卻一路 +10% 以上，代表 不可控費用沒有等比例縮減，固定成本被攤到較少人身上。 這個訊號被「人事費下降」完全蓋住，必須拆解到人均維度才能挖出。
意義：縮編節省的薪資成本，部分被未縮減的固定費用吃掉 —— 真實的單位人力成本反而上升。
Finding 3 · 主因科目自動定位
「固定擴張」每月真主因都是同三項
系統 topYoYRisers 演算法跨月一致指出： 折舊-房屋建築（去年同期 0 → 今年 11~16 萬）、 折舊-儀器設備（+50~130%）、保險費（0 → 10~17 萬）。 推論：2024 下半年新增房屋 / 儀器資產，2025 起攤提入帳。
意義：傳統「總費用率」與「不可控 YoY」（被薪資縮減蓋成負值）裡完全看不到， 只有人均 + 科目級拆解才挖得出來 —— 這是真正的固定成本擴張源頭。
06 — Innovation

技術亮點

在標準 BI 工具的能力之外，本平台針對品保費用的特性設計了七項關鍵技術機制。

1.純前端互動報告（零後端依賴）

所有資料以常數形式 inline 注入 HTML，搭配 Chart.js 4.4 與原生 JS。 單一 .html 檔可寄送、可離線開、可上 GitHub Pages， 主管收到郵件後雙擊即可看到完整互動報告， 無需登入任何系統、無需 VPN、無資料庫成本。

2.檔案監聽 + Debounce 自動觸發

watch.js 透過 fs.statSync 監測 Excel mtime 異動， 3 秒 debounce 排除 Excel 存檔過程的多次寫入事件， 搭配 pm2 常駐確保系統重開機自動重啟。使用者操作體驗 = 無感。

3.Claude API 智能摘要

整合 @anthropic-ai/sdk，將結構化指標餵給 Claude， 產出符合品保語境的中文 bullets。摘要內容包含 MoM / YoY 解讀、管制帶警示、 異常科目白話化說明，把「需要分析師才能寫的段落」自動化。

4.統計管制圖（UCL / LCL / σ）

費用占比以歷史 27 個月計算 μ ± 1σ 管制線，疊加 MA3 / MA6 移動平均與三段管制帶。 門檻取自歷史 P25 / P75 校準，提供客觀的「異常 vs 正常」分界， 取代過去依賴經驗的主觀判斷。

5.三維 Verdict 規則引擎

布林旗標組合（ctrlBad / uncBad / perCapBad） 映射到 6 種預設判讀文字 + 對應等級色（🟢 / 🟡 / 🔴 / 🟣）。 失控情境自動追加 YoY +5 萬以上的 top 3 主因科目， 主管看到的不是數字而是行動建議。

6.科目級 YoY 漲幅追蹤

topYoYRisers 按 FIXED / VARIABLE 分類加總， 過濾絕對差 ≥ 5 萬，依漲幅排序取 top N。 直接定位到「哪個科目」漲了「多少錢」， 而不是只說「不可控費用上升了」。

7.多維篩選 + Sticky 篩選列

年 / 月 / 廠多選即時切換，所有圖表同步重繪。 IntersectionObserver 偵測 sentinel，捲動時篩選列自動黏在頂端， 主管想看哪個切片就直接點，不用回部門重做報告。
