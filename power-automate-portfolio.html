#01 Automated
客訴 Action Item 建立 → 自動建立 Planner 任務
新增客訴 Action Item 時，自動建立 Planner 任務、指派負責人並發送 Teams 通知，同步回寫任務 ID 至 Lists，形成完整任務追蹤鏈。
⚡觸發：新增 Action Item → 建立任務 + 通知 + 回寫 ID
Lists Planner Teams
#02 Automated
客訴 FA 建立 → 自動發送 Teams Adaptive Card
當客訴 FA 案件建立時，自動發送 Adaptive Card 至 Teams 頻道，即時通知相關人員，確保資訊第一時間觸達。
⚡觸發：FA 案件建立 → Adaptive Card 推播至頻道
Lists Teams
#03 Automated
客訴案件同步給業支（FAE & 業支記錄表）
客訴案件建立或更新時，自動同步資料至 FAE 業支記錄表，依 FA No. 判斷執行更新或新增，確保跨部門資料一致。
⚡觸發：案件建立/更新 → 依 FA No. 判斷 Upsert
Lists Lists（業支表）
#04 Automated
同主案件最大 Warranty 係數 → 回寫主案件
自動抓取同一主案件下所有子案件的 Warranty 係數，取最大值後回寫至主案件，作為整體風險評估依據。
⚡觸發：進度更新建立/修改 → 聚合最大值 → 回寫
Lists
#05 Automated
客訴進度 FA Qty 加總 → 回寫主案件
新增後續改善項目時，自動統計同一主案件下所有項目的 FA Qty 加總，並回寫至主案件「自動加總 FA Qty」欄位。
⚡觸發：項目新增 → Sum FA Qty → 回寫主表
Lists
#06 Automated
同主案件最大 Key Account 等級 → 回寫主案件
自動抓取同一主案件下所有子案件的 Key Account 等級，取最大值後回寫至主案件，作為案件重要度判斷依據。
⚡觸發：進度更新建立/修改 → Max KA 等級 → 回寫
Lists

同主案件 Error Code RPN 最大值 → 回寫主案件
自動抓取同一主案件下所有 Error Code 的 RPN 值，計算最大值後回寫，確保案件風險等級即時反映最嚴重問題。
⚡觸發：進度資料建立/更新 → Max RPN → 回寫

#08 Automated
Lists 被修改 → 找到對應 Planner Task → 更新 Planner
當 Lists 資料更新時，自動查找對應的 Planner 任務並同步更新內容，確保兩端資料始終一致。
⚡觸發：Lists 修改 → 查詢 Task ID → 更新 Planner

#09 Automated
Planner 任務狀態 → 自動同步 Lists（完成 / 未完成）
Planner 任務完成或狀態變更時，自動同步對應 Lists Action Item 狀態，確保任務執行與資料系統一致。
⚡觸發：Planner 狀態變更 → 更新 Lists 欄位
Planner Lists
#10 Scheduled
定時檢查 Planner「被取消完成」的任務 → 復原 Lists
監控 Planner 任務是否從「完成」被改回「未完成」，自動同步更新 SharePoint Lists 中對應欄位，防止狀態不同步。
🕐定時排程 → 掃描狀態變更 → 復原 Lists 欄位
Planner Lists
#11 Automated
Planner 任務完成 → 審核流程 → 回寫核准狀態
Planner 任務完成時，自動發起審核流程。審核通過後回寫核准狀態與核准資訊至 Lists，形成完整閉環管理機制。
⚡觸發：Planner 完成 → Approval → 核准狀態回寫
